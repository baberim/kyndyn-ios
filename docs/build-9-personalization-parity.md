# Build 9 — Personalization Parity

Build 9 brings Kyndyn's native collection closer to the established Rowan
artwork while separating everyday customization from protected household
administration.

## Everyday Settings

The Settings tab is available to the active profile without Parent
authentication. It contains profile color, companion, background, app-icon,
and family-setup help entry points. Household membership, sync, reminders,
backups, permissions, rewards, and security remain in Parent.

App-icon choice is local to the installation. Profile color, companion, and
background remain part of the synchronized profile record.

## Collection additions

The native app includes the full approved Rowan companion set: Spark, Orbit,
Pixel, Comet, Bop, Penguin, Bee, Cactus, Cloud, Dino, Jellyfish, Astronaut,
Deer, Ninja, Star, Petey, Kaleido, and Selene.

It also includes Meadow, Bedroom, Cloud, Aquarium, Arcade, Rainbow Summit,
Crystal Dream Cave, Moon Garden, Starry Campout, and Space Station scenes.
Generic locked-placeholder images are intentionally not presented as scenes.

Existing Rowan milestone rules are retained where defined. Additional artwork
uses deterministic quest, streak, badge, level, or family-reward milestones.
No random reward selection or behavioral profiling is introduced. Parents can
still grant a collection item manually.

Railway household records, backups, logs, secrets, and custom runtime state are
not part of the application bundle. Only the explicitly approved companion
artwork was copied from the private Railway volume.
