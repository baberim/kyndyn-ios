The source companion exports are approved app catalog assets, not household
profiles or runtime records. Solid chroma backgrounds were removed locally
where required for native transparency; artwork was otherwise retained. The
additional catalog artwork explicitly authorized by the project owner was
downloaded as image content only. No household JSON, names, backups, logs, or
other private runtime data was copied into the repository.

The app icon at
`kyndyn/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` was
provided directly by the project owner during Development CloudKit Validation
0.5. The native copy is mechanically flattened to an opaque 1024×1024 PNG for
Apple asset-catalog compliance; the supplied source file is not committed.

The alternate pastel icon at
`kyndyn/Resources/Assets.xcassets/AppIconPastel.appiconset/AppIconPastel-1024.png`
was also supplied directly by the project owner. The matching preview assets are
derived copies used only by the in-app icon picker.

The launch-screen wordmark at
`kyndyn/Resources/Assets.xcassets/KyndynSplash.imageset/KyndynSplash.png` was
provided directly by the project owner for Build 5 and is committed unchanged.
